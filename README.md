# Paths of Mastery

Мод для Minecraft 1.21.1 (NeoForge), добавляющий глубокую систему прокачки с 12 уникальными путями развития.

## 🎮 Основные возможности

- **12 уникальных путей**: Воин, Охотник, Шахтёр, Фермер, Алхимик, Чародей, Исследователь, Защитник, Пиромаг, Криомаг, Инженер, Ночной Странник
- **20 уровней** в каждом пути
- **Выбор 3 путей** на персонажа (постоянный выбор)
- **Система квестов** для прогрессии
- **Синергии** между путями (бонусы за комбинации)
- **Финальные способности** (Ultimate) на 20 уровне
- **Сбалансированная прогрессия** без дисбаланса
- **Полная поддержка мультиплеера**

## 📋 Пути развития

### ⚔️ Путь Воина
- **Бонусы**: Урон в ближнем бою, здоровье, сопротивление урону
- **Финальная способность**: Ярость Берсерка (5 мин кулдаун)
  - 15 сек: +100% урона, +50% скорости атаки, иммунитет к отбрасыванию

### 🏹 Путь Охотника
- **Бонусы**: Урон из лука, точность, скорость
- **Финальная способность**: Залп стрел (3 мин)
  - Выпускает 20 стрел веером

### ⛏️ Путь Шахтёра
- **Бонусы**: Скорость копания, шанс на дополнительные руды, ночное зрение
- **Финальная способность**: Жила удачи (10 мин)
  - 2 мин: x3 ресурсы, 50% шанс редких руд

### 🌾 Путь Фермера
- **Бонусы**: Ускорение роста растений, больше дропа с ферм
- **Финальная способность**: Урожайный сезон (15 мин)
  - Мгновенно выращивает все растения в радиусе 20 блоков

### 🔮 Путь Алхимика
- **Бонусы**: Усиление зелий, длительность эффектов
- **Финальная способность**: Философский камень (20 мин)
  - Превращает обычные материалы в ценные

### 📚 Путь Чародея
- **Бонусы**: Лучшие зачарования, меньше затрат опыта
- **Финальная способность**: Совершенное зачарование (30 мин)
  - Следующее зачарование получает максимум всех чар

### 🏃 Путь Исследователя
- **Бонусы**: Скорость передвижения, сопротивление падению, подводное дыхание
- **Финальная способность**: Скачок измерений (5 мин)
  - Телепорт на 100 блоков в направлении взгляда

### 🛡️ Путь Защитника
- **Бонусы**: Увеличение брони, отражение урона, регенерация
- **Финальная способность**: Несокрушимая крепость (8 мин)
  - 30 сек: иммунитет к урону, отражение 50% урона

### 🔥 Путь Пиромага
- **Бонусы**: Огненный урон, иммунитет к огню, поджигание врагов
- **Финальная способность**: Метеоритный дождь (7 мин)
  - Призывает 10 огненных метеоритов

### ❄️ Путь Криомага
- **Бонусы**: Замедление врагов, морозный урон, устойчивость к холоду
- **Финальная способность**: Ледниковая эпоха (7 мин)
  - Замораживает всех врагов в радиусе 30 блоков на 10 сек

### ⚡ Путь Инженера
- **Бонусы**: Бонусы к редстоуну, автокрафт, улучшение инструментов
- **Финальная способность**: Автоматон (10 мин)
  - Призывает робота-помощника на 5 минут

### 🌙 Путь Ночного Странника
- **Бонусы**: Бонусы ночью, невидимость в темноте, урон по нежити
- **Финальная способность**: Теневое слияние (4 мин)
  - 60 сек: полная невидимость, +200% скорости

## 🌟 Синергии

Комбинации путей дают дополнительные бонусы:

- **Воин + Охотник** = Мастер оружия (+10% урона любым оружием)
- **Воин + Защитник** = Непоколебимый (+20% защиты, -10% получаемого урона)
- **Пиромаг + Криомаг** = Мастер стихий (переключение между огнём и льдом)
- **Алхимик + Чародей** = Архимаг (зелья дают бонус к зачарованиям)
- **Шахтёр + Инженер** = Индустриал (автоплавка руд, +30% к механизмам)
- **Фермер + Алхимик** = Травник (растения дают алхимические ингредиенты)
- **Исследователь + Шахтёр** = Спелеолог (видение руд сквозь стены)
- И многие другие...

## ⌨️ Управление

- **P** - Открыть меню путей
- **R** - Использовать финальную способность (требуется 20 уровень)

## 🎯 Прогрессия

### Система уровней
- **Уровни 1-5**: Базовые бонусы (+2-5%)
- **Уровни 6-10**: Улучшенные бонусы (+5-10%)
- **Уровни 11-15**: Продвинутые способности (+10-15%)
- **Уровни 16-19**: Мастерство (+15-20%)
- **Уровень 20**: Финальная способность

### Получение опыта
Опыт для путей начисляется за выполнение тематических действий:
- **Воин**: Убийство мобов в ближнем бою
- **Охотник**: Убийство мобов из лука
- **Шахтёр**: Добыча руд и блоков
- **Фермер**: Выращивание растений, разведение животных
- И т.д.

### Квесты
Каждый путь имеет уникальные квесты, которые открываются при достижении определённых уровней. Квесты дают большое количество опыта и необходимы для быстрой прокачки.

## 🔧 Технические характеристики

- **Версия Minecraft**: 1.21.1
- **Загрузчик**: NeoForge 21.1.72
- **Требования**: Java 21

## 📦 Установка

1. Установите NeoForge 1.21.1
2. Скачайте мод
3. Поместите `.jar` файл в папку `mods`
4. Запустите игру

## 🛠️ Сборка из исходников

```bash
# Клонируйте репозиторий
git clone <repository-url>
cd PathsOfMastery

# Соберите мод
./gradlew build

# Собранный .jar будет в build/libs/
```
